# Man vs Machine on Oslo Børs

This repository contains the codebase for the project **"Man vs Machine on Oslo Børs"**, which evaluates the performance of machine learning models against traditional finance factors on the Oslo Stock Exchange. The project specifically explores the impact of combining traditional equity factors (e.g., size, momentum, volatility) with "Smart Money" / "Best Ideas" signals derived from mutual fund holdings.

This project is part of a master's thesis submitted to NHH Norwegian School of Economics. The full thesis, including the complete literature review and discussion, will be linked here once published. *[link to be added]*

## Project Structure

The workflow is divided into four Jupyter Notebooks, run in sequence:

### 1. `Data_Cleaning.ipynb` — Data Cleaning & Feature Engineering
- **Data Preprocessing:** Standardizes ISIN codes, aligns monthly trade dates, and filters for relevant equity types (Ordinary Shares, Primary Capital Certificates, etc.). Flags delistings (bankruptcy vs. M&A) and assigns spell IDs to handle gaps in a security's trading history.
- **Feature Engineering:** Calculates key financial metrics such as Market Cap (log size), Turnover, Momentum (6-month and 12-month), Reversal (1-month), and Volatility (3-month and 6-month). Cross-sectionally ranks and z-scores each feature by month.
- **Target Variable:** Computes the 1-month forward return, winsorizing at the 1st and 99th percentiles to handle anomalies.
- **Smart Money Integration:** Merges "Best Ideas" data from mutual funds (Top 10 conviction counts, average fund weights, fund breadth) into the modern track dataset (post-2010). Both raw and cross-sectionally z-scored features are produced.
- **Outputs:** `processed_equity_data.csv`, `investable_universe.csv` (historical track), `modern_equity_dataset.csv` (modern track with mutual fund signals).

### 2. `Machine_learning.ipynb` — Machine Learning
- **Model Training:** Utilizes Scikit-Learn and XGBoost to train multiple models: Ridge Regression, Random Forest, XGBoost, and a Multi-Layer Perceptron (MLP) Neural Network, for both the historical and modern tracks.
- **Cross-Validation:** Uses a chronological "Time Machine" split (`PredefinedSplit` / `GridSearchCV`) with fixed validation (from 2019) and test (from 2022) windows to ensure strict out-of-sample validation and prevent look-ahead bias.
- **Ensemble Predictions:** Combines the predictions from all models into a single robust ensemble signal.
- **Feature Importance:** Extracts and visualizes XGBoost feature importances (gain), contrasting the historical baseline with the modern track augmented by mutual fund conviction.
- **Outputs:** `historical_predictions.csv`, `modern_predictions.csv`.

### 3. `Simulation.ipynb` — Portfolio Simulation
- **Backtesting Engine:** Simulates monthly trading strategies (Long-Only and Long-Short) using the ML predictions to target the top 20% (Long) and bottom 20% (Short) of the universe.
- **Benchmark:** Loads Ødegaard's value-weighted (VW) Norway market portfolio as the market benchmark.
- **Transaction Costs:** Accounts for realistic monthly turnover and transaction costs (15 bps).
- **Performance Metrics:** Computes the Rank Information Coefficient (IC) across the full universe to measure the predictive power of each model's signal.
- **Outputs:** Cumulative return plots for each strategy; exports portfolio return series (e.g. `portfolio_simulation_returns_mod.csv`) for use in the Evaluation notebook.

### 4. `Evaluation.ipynb` — Strategy Evaluation
- **Risk-Adjusted Performance:** Calculates Annualized Returns, Annualized Volatility, Sharpe Ratios, and Maximum Drawdowns for the ML ensembles versus the Traditional Momentum baseline and market benchmark, for both the historical and modern tracks.
- **Alpha Regressions:** Runs CAPM (1-factor), Fama-French (3-factor), and Carhart (4-factor) regressions to evaluate statistically significant alpha generated by the strategies.
- **Factor Loadings:** Breaks down the Long-Only ("mutual fund") and Long-Short ("hedge fund") portfolio exposures to Market, SMB (Size), HML (Value), and UMD (Momentum) factors to "open the black box" of the ML algorithms.
- **Portfolio Characteristics:** Generates appendix tables summarizing the characteristics (e.g. size) of the stocks held by each strategy, for both tracks.

```
  └─> modern_equity_dataset.csv ─────┐    │
                                      ▼    ▼
                          Machine_learning.ipynb
                              ├─> historical_predictions.csv
                              └─> modern_predictions.csv
                                      │
                                      ▼
                              Simulation.ipynb
                                      │
                                      ▼ (portfolio return series)
                              Evaluation.ipynb
```

## Key Findings
- **Machine Learning Edge:** The ML Ensemble strategies significantly outperform traditional baseline models (like 12-month Momentum) in terms of Annualized Return and Sharpe Ratio.
- **Significant Alpha:** The Long-Short Modern Ensemble strategy delivers robust Carhart 4-factor alpha, indicating that the returns are not just compensating for standard equity risk exposures.
- **Smart Money Value:** Incorporating "Best Ideas" signals from mutual fund portfolios enhances predictive accuracy and helps the models navigate modern market conditions on the Oslo Børs.

## Data Availability

The datasets used in this project are **not included** in this repository:

- **Oslo Børs equity data and mutual fund holdings data** were obtained through NHH Norwegian School of Economics' institutional data access and cannot be redistributed due to data provider licensing restrictions.
- **Market, risk-free rate, and Fama-French/Carhart factor data** for Norway are publicly available from Bernt Arne Ødegaard's dataset at [ba-odegaard.no/financial_data](https://ba-odegaard.no/financial_data/) and should be downloaded directly from the source rather than from this repo.

See [`Data/README.md`](Data/README.md) for the full file-by-file breakdown, sourcing, and how to reproduce the pipeline with equivalent data access.

**Citation:** Ødegaard, Bernt Arne. *"Empirics of the Oslo Stock Exchange: Basic, Descriptive, Results 1980–2024."* Available at ba-odegaard.no/financial_data.

## Usage
Run the notebooks in the following logical order:
1. `Data_Cleaning.ipynb`
2. `Machine_learning.ipynb`
3. `Simulation.ipynb`
4. `Evaluation.ipynb`

Each notebook reads the CSV outputs of the previous stage from a shared `../Data/` directory, so notebooks must be run in order the first time (or whenever upstream data changes). See the Data Availability section above for how to obtain the required input files.
