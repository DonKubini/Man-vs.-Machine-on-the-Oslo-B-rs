# Data

The raw and intermediate data files used by this project are **not included** in this repository. This folder documents what each file is, where it comes from, and how to obtain or regenerate it.

## Proprietary / institutional-access data (not redistributable)

These files were obtained through NHH Norwegian School of Economics' institutional data access and cannot be published here due to data provider licensing restrictions.

| File | Description | Used in |
|---|---|---|
| `master_equity_panel_1980_2024.csv` | Raw Oslo Børs equity panel (prices, shares issued, turnover, security type) | `Data_Cleaning.ipynb` |
| `portfolios_master_updated.csv` | Mutual fund monthly holdings ("Best Ideas" / Smart Money data) | `Data_Cleaning.ipynb` |

If you have equivalent institutional access to Oslo Børs equity data and mutual fund holdings data, the notebooks can be re-run end-to-end by placing files with the same schema in this folder under the same names.

## Public academic data (freely available, cite on use)

These files are from Bernt Arne Ødegaard's publicly available dataset on Norwegian asset pricing, available at [ba-odegaard.no/financial_data](https://ba-odegaard.no/financial_data/) (not redistributed here — please download directly from the source).

| File | Description | Used in |
|---|---|---|
| `Norway_market_portfolios_monthly.csv` | Value-weighted (VW) Oslo Børs market portfolio returns | `Simulation.ipynb`, `Evaluation.ipynb` |
| `Norway_Rf_monthly.csv` | Norwegian monthly risk-free rate | `Evaluation.ipynb` |
| `Norway_pricing_factors_monthly.csv` | Fama-French (SMB, HML) and Carhart (UMD) factors for Norway | `Evaluation.ipynb` |

**Citation:** Ødegaard, Bernt Arne. *"Empirics of the Oslo Stock Exchange: Basic, Descriptive, Results 1980–2024."* Available at ba-odegaard.no/financial_data.

## Files generated by this pipeline

All other CSVs referenced in the notebooks (e.g. `processed_equity_data.csv`, `investable_universe.csv`, `modern_equity_dataset.csv`, `historical_predictions.csv`, `modern_predictions.csv`, `portfolio_simulation_returns_*.csv`) are intermediate outputs generated by running the notebooks in order — see the main README for the full data flow. They are excluded from version control via `.gitignore` since they are derived from the restricted-access files above.
